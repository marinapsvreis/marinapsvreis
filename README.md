# Hi, I'm Marina Valente 👋

**Senior Frontend Engineer | React, TypeScript & Next.js | Full Stack Experience**

I build web applications with a focus on frontend architecture, design systems, and user experience. My full stack experience includes Node.js, NestJS, API integrations, and relational databases.

## Selected work

- **iFood** — Developed partner onboarding flows with React and TypeScript in a microfrontend architecture. Contributed to a shared design system and built Databricks notebooks to evaluate releases through gradual rollouts and A/B tests.
- **Cogna** — Migrated a legacy Angular campaign application to Next.js, built a reusable component library documented with Storybook, and used n8n to turn marketing requests into Jira issues.
- **Alterdata** — Helped migrate cash flow features from a Delphi desktop ERP to the web using Vue.js and C#/.NET. Worked on optimizing database queries for dashboards with large datasets and complex filters.
